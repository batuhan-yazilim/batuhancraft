# 🎮 Batuhan Craft

**Batuhan Craft**, HTML, CSS ve JavaScript kullanılarak geliştirilen, tarayıcı üzerinden oynanabilen basit ve eğlenceli bir **craft / sandbox temalı web oyunudur**.

Bu proje, hem eğlence hem de **web tabanlı oyun geliştirme pratiği** amacıyla oluşturulmuştur.

---

## 🕹️ Oyun Hakkında

**Batuhan Craft** oyununda oyuncular:
- Haritada gezinebilir  
- Bloklarla etkileşime girebilir  
- Basit craft / inşa mantığını deneyimleyebilir  
- Kurulum yapmadan, doğrudan tarayıcıdan oynayabilir  

Amaç, sade ama geliştirilebilir bir oyun altyapısı sunmaktır.

---

## 🛠️ Kullanılan Teknolojiler

- **HTML** — Oyun yapısı  
- **CSS** — Arayüz ve görsel tasarım  
- **JavaScript** — Oyun mekaniği ve etkileşim sistemi
