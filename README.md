🎮 Batuhan Craft

Batuhan Craft is a simple and fun sandbox / craft themed web game that can be played via the browser, developed using HTML, CSS and JavaScript.

Players can explore, interact with blocks, and have a free gameplay experience with basic game mechanics.

🕹️ About the Game

In Batuhan Craft game:

You can navigate on the map

You can interact with blocks

You can experience simple craft / building logic

You can play via browser without installation

This project was made for both entertainment and web-based game development practice.

🛠️ Technologies Used

HTML — Game structure

CSS — Design and interface

JavaScript — Game mechanics and interactions

▶️ How to Play?

Download or clone the repo:

git clone https://github.com/username/batuhan-craft.git


Open index.html file

The game runs automatically in the browser 🎮

✨ Features

🧱 Craft / block themed gameplay

🌍 Simple exploration system

⚙️ Dynamic mechanics with JavaScript

💻 No installation, playable from browser

🔄 Infrastructure open to development
